# Design: Runtime & Codegen Fixes

## Context

Dans `backend/mlblock/core/generator.py`, `generate_code` concatène les sources brutes des fonctions de blocs renvoyées par `_source_for(b_type)`. Étant donné que les fichiers de blocs définissent tous `from __future__ import annotations`, ces déclarations se retrouvent disséminées dans le corps du script, violant la syntaxe Python.
De plus, 6 blocs définissent des classes PyTorch avec une casse erronée (`Avgpool2D`, `AdaptiveAvgpool2D`, `AdaptiveMaxpool2D`, `Lstm`, `Gru`, `Rnn`), et `execution.py` utilise un littéral fixe pour `BACKEND_URL` en mode local.

## Goals / Non-Goals

**Goals:**
- Garantir que `generate_code` produit un script autonome avec `from __future__ import annotations` en tête unique.
- Aligner les identifiants de classes PyTorch sur l'API officielle `torch.nn`.
- Permettre à `LocalBackend` de relayer `BACKEND_URL` configurée par l'environnement.
- Supprimer les reliquats de répertoires vides.

**Non-Goals:**
- Ne pas refondre les stages du pipeline (objet de la Spec 2).
- Ne pas modifier le frontend (objet de la Spec 3).

## Decisions

1. **Assainissement des sources de blocs dans `generator.py`** :
   - Ajouter `lines = ["from __future__ import annotations", '"""Generated by MLBlock."""', ""]` en début de `generate_code`.
   - Lors de la récupération de la source via `_source_for(b_type)`, filtrer systématiquement toute ligne correspondant au pattern `^from __future__ import annotations\s*$`.
2. **Correction des symboles PyTorch** :
   - Remplacer les appels fautifs dans `backend/mlblock/blocks/regroupement-F59E0B/` et `backend/mlblock/blocks/sequences-8B5CF6/`.
   - Ajuster `multihead_attention.py` pour transmettre `(in_1, in_1, in_1)`.
3. **Transmission de l'environnement dans `LocalBackend`** :
   - Remplacer `"BACKEND_URL": "http://localhost:8000"` par `"BACKEND_URL": os.environ.get("BACKEND_URL", "http://localhost:8000")`.

## Risks / Trade-offs

- Risque minime : les blocs de pooling et de séquences corrigés ne modifient pas leur signature d'interface, seulement l'implémentation interne qui était en échec systématique.

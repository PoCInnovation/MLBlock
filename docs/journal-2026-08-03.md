## 3. Performance Render (`render.yaml`)

D'après la doc Render (via Context7) :

- **`uv run` → `.venv/bin/uvicorn`** : évite la résolution d'environnement au boot (le warning `VIRTUAL_ENV mismatch` disparaît)
- **`pip install uv` supprimé** : Render intègre uv automatiquement si `uv.lock` existe
- **Build filters** : backend et frontend ne se rebuildent plus mutuellement quand l'un change
- **`fetchCatalog` retry auto** : 5 tentatives espacées de 15s pour réveiller le backend endormi (free tier Render)
- **Timeout axios 10s → 60s** : laisse le temps au cold start free tier (~1 min)

**Limite connue** : le spin-down free tier (15 min d'inactivité) ne se règle pas dans le blueprint — il faut un plan payant ou un ping externe.

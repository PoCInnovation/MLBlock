# STORYLINES — MLBlock démo v2

Chose one thing: **« Tu peux classer 178 vins sans écrire une ligne de modèle. »**
Spine : un étudiant, un jeu (wine, 178 vins, 3 classes), un objectif (savoir lesquels se ressemblent).

## A — « L'étudiant × avant/après » (RETENUE)
- **World** : deux mondes qui se répondent. Avant = terminal sur papier clair. Après = le vrai MLBlock sombre.
- **Device** : un étudiant bloqué par une erreur de code, puis le même objectif dans MLBlock.
- **Form** : « object becomes the world » — le message d'erreur est remplacé par le bouton `Lancer` qui grandit jusqu'à remplir l'écran.
- **First 2 s** : terminal papier, `ValueError` déjà affiché sur `fit(X, y)`.
- **Beats** : hook → tension → reveal → proof (assemble / corrige / évalue) → payoff (le run) → claim → end card.
- **Look** : papier `#E9E4DC` + encre `#1B1714` puis thème sombre réel `#171311`.
- **Sound** : silence de musique pendant l'échec ; la musique entre au reveal ; un riser sur le payoff ; effets seulement sur de vraies actions. Pas de musique si aucun fournisseur n'est disponible (dit explicitement).

## B — « Le résultat d'abord »
- **World** : le nuage t-SNE plein écran. **Device** : le résultat d'abord, puis la caméra recule pour montrer les 9 blocs. **Form** : endless zoom out.
- Plus accrocheur, mais l'étudiant disparaît : on perd la situation qu'un inconnu reconnaît.

## C — « Avant/après pur » (le plus audacieux)
- **World** : écran partagé. **Device** : 396 lignes de code contre 9 blocs. **Form** : split screen to one.
- Écarté : les 396 lignes sont du code **généré** par MLBlock, pas du code d'étudiant ; les présenter comme « l'avant » serait faux.

## Choix
A : seule piste où un inconnu suit une situation vraie (l'échec d'un étudiant) et où chaque plan en cause le suivant. Le mix demandé (étudiant + avant/après) en est exactement la forme.
